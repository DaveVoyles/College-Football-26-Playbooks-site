# CFB26 Playbook Site 🏈

GitHub Pages site for the [CFB26 Playbook Library](https://github.com/DaveVoyles/College-Football-26-Playbooks).

Features:
- 7 offensive scheme guides (Air Raid, Pro Style, Spread, Veer & Shoot, West Coast, Option, Run & Shoot)
- 6 interactive WebGL 3D visualizations (Three.js)
- Team-to-scheme guide, route concepts cheat sheet, call sheet template
- Dark/light mode with palette cycling
- PWA with offline support

**Live site:** [davevoyles.github.io/College-Football-26-Playbooks-site](https://davevoyles.github.io/College-Football-26-Playbooks-site/)
